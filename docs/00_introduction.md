# Introduction

This guide provides Zscaler Professional Services (PS) consultants with step-by-step instructions for designing, deploying, executing, and remediating AI Red Teaming engagements against Microsoft Copilot–based applications.

It covers all phases from initial scoping to governance, grounded in documented Zscaler AI Red Teaming platform capabilities.

---

## Scope

This guide covers the following Copilot surfaces and engagement types:

- **Copilot Studio agents** — Bot Framework / Direct Line–style APIs, backed by Azure OpenAI / Azure AI Foundry
- **Copilot for Microsoft 365 (M365)** — with enterprise data access
- **Custom Copilot integrations** built by the customer — Azure AI Foundry endpoints, LangChain-based RAG, or orchestration APIs
- **Pre-production certification engagements** and post-production recurring testing
